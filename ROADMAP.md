# Roadmap

This roadmap tracks the direction for `OpenClaw-Feishu-Multi-Agent` as both:

- an open source orchestration project for external developers
- a production-ready delivery toolkit for customer-facing Feishu multi-agent deployments

## Near Term

- keep `V5.1 Hardening` stable as the single public mainline
- improve README discoverability and quickstart quality
- expand secret-safety and publishing hygiene
- keep examples sanitized and release-safe
- maintain strong regression coverage for controller / outbox / callback sink / rollup

## Mid Term

- add more public-safe example teams for different role mixes
- improve docs for onboarding, architecture, and troubleshooting
- add more CI checks for links, sanitization, and template consistency
- refine the supervisor final rollup so it reads like a stronger decision memo across more scenarios

## Long Term

- become the reference open source template for Feishu-based multi-agent team orchestration
- support richer team topologies while keeping the current deterministic control-plane guarantees
- build a clearer ecosystem for operators, contributors, and delivery partners
- become easier to fork, brand, and deploy in real customer environments
